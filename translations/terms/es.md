# Spanish (es, WordPress es_ES) word list

Neutral Spanish, understandable in Latin America; impersonal phrasing, "usted" only where unavoidable.

"Confirmed" = found in the WordPress es glossary (translate.wordpress.org/locale/es/default/glossary/). The glossary page could only be read up to the entry "manage"; terms marked "WP core usage" follow WordPress core's es_ES wording from memory and were not re-checked online (core string search was rate-limited with HTTP 429).

## Ambiguous strings

- "Rolls out player updates." Rendered as "Despliega actualizaciones del reproductor."
- "Syncs the clock." / "Limits clock requests." Rendered literally ("reloj"); likely a time-sync service.
- "Records which campaign or website brought you here, saved with your order." Uses "le" (usted) as the English addresses "you".
- "Resumes a video where you left off." Rendered impersonally ("donde se dejó").
- "Stores the group the visitor belongs to." "Group" kept as "grupo" (test or user group).
- "Tells visitors apart on the publisher's site." "publisher" rendered "editor" (site publisher).
- "Shows whether stored user attributes are current." Rendered as "Indica si ... están actualizados."
- "PayPal's tag that its checkout adds..." "checkout" rendered "pago".
- "Carries data across a test redirect." "Transporta datos durante una redirección de prueba."
