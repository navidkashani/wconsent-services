## Ambiguous strings

- "Tells visitors apart." / "Tells devices apart." / "Tells browsers apart.": rendered as "Distingue i visitatori / i dispositivi / i browser."
- "Stores the signed-in user." : read as the logged-in user (WordPress sense), "Memorizza l'utente connesso."
- "Stores the group the visitor belongs to.": read as a test or segment group, "gruppo".
- "Syncs the clock.": read as time synchronisation with the server.
- "Rolls out player updates.": read as gradual release of new player versions.
- "Shows whether stored user attributes are current." : kept literal.
