Confirmation status: translate.wordpress.org returned HTTP 429 (rate limit) for the glossary page and most searches. Only the terms marked "confirmed" were verified against WordPress core's nl translation (cookies, session, device, embed). The rest follow standard WordPress nl usage from memory and should be spot-checked.

## Ambiguous strings

- "Syncs the clock." / "Limits clock requests." (Amazon-type cookies): translated literally as clock synchronisation.
- "Tells browsers apart." / "Tells devices apart.": "Onderscheidt browsers/apparaten van elkaar."
- "Where your visit came from (...)" and "brought you here": the English uses "you/your"; rendered impersonally ("de bezoeker", "het bezoek") to avoid a pronoun.
- "Needed for the Spotify embed to work.": "ingesloten Spotify-speler" avoided; kept literal.
- "Holds the advertising ID on mobile devices.": ID kept as "ID".
